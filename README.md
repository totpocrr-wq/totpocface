# FaceSwap Studio

Десктопное приложение для записи видео с веб-камеры с детекцией скелета и
последующей заменой лица на лицо из фото или видео-источника. Все экспортируемые
видео автоматически маркируются водяным знаком «AI GENERATED» в соответствии с
требованиями EU AI Act.

## Возможности (v0.1.0)

- 🎥 Поиск и подключение веб-камер
- 🦴 Детекция позы человека (скелет) поверх живого видео — **MediaPipe**
- ⏺ Запись видео в `.mp4`
- 🖼 Загрузка фото или видео с лицом-источником (drag & drop)
- 🔄 Покадровая замена лица — **InsightFace** (`inswapper_128`)
- 🏷 Автоматический водяной знак на всех экспортах
- 📁 Результаты в папке `output/`

## Системные требования

| Компонент | Минимум | Рекомендуется |
|-----------|---------|---------------|
| ОС | Windows 10 (64-bit) | Windows 11 |
| RAM | 8 ГБ | 16 ГБ |
| GPU | — (CPU работает) | NVIDIA RTX с CUDA |
| Свободное место | 5 ГБ | 10 ГБ |

> **Важно:** на CPU обработка минуты видео занимает 5–15 минут. На NVIDIA RTX
> с `onnxruntime-gpu` — около 30 секунд.

## Разработка (для тебя)

### 1. Установка

Требуется **Python 3.10 или 3.11** (3.12+ пока не поддерживается из-за MediaPipe).

```bash
git clone <repo>
cd FaceSwapApp
setup.bat
```

Или вручную:

```bash
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
```

### 2. Запуск из исходников

```bash
venv\Scripts\activate
python main.py
```

### 3. Сборка `.exe`

Запусти:
```bash
build.bat
```

Получишь:
- `dist/FaceSwapStudio/` — портативная сборка
- `Output/FaceSwapStudio_Setup.exe` — инсталлятор (если установлен Inno Setup)

> Inno Setup скачать: https://jrsoftware.org/isinfo.php

```
├── build.spec                   # PyInstaller config
├── installer.iss                # Inno Setup config

```

## Полный flow

1. **Запуск камеры** → MediaPipe рисует скелет поверх кадра.
2. **Запись** — кнопка «Начать запись», в `output/` появится `record_<timestamp>.mp4`.
3. **Загрузка лица** — drag & drop или «Выбрать файл». Поддержка фото
   (`.jpg/.png/.webp`) и видео (`.mp4/.mov/.avi`). Из видео берётся лучший кадр.
4. **Замена лица** — кнопка «Заменить лицо в записи».
   В `output/` появится `swapped_<timestamp>.mp4` с водяным знаком.

## Известные ограничения v0.1

- ❌ Нет редактирования (часы, серьги, изменение черт) — это в v0.2 через Stable Diffusion + ControlNet
- ❌ Нет real-time preview face swap (только постобработка)
- ❌ На CPU обработка медленная — на минуту видео уходит 5–15 минут
- ⚠️ Не все фото-источники сработают — нужен чёткий фронтальный портрет
- ⚠️ Антивирусы / Windows SmartScreen могут ругаться на неподписанный `.exe` —
  это решается покупкой code-signing сертификата (~200 €/год)
