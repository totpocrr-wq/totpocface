# Запуск без сборки .exe — для тебя

Эта инструкция — как запустить приложение прямо из исходников, без всяких
GitHub и установщиков. Подходит, чтобы протестировать, что всё работает.

---

## Что нужно сделать (один раз)

### 1. Установи Python 3.11

Скачай отсюда: https://www.python.org/downloads/release/python-3119/

Прокрути вниз до раздела «Files» → **«Windows installer (64-bit)»**.

При установке **обязательно поставь галочку «Add python.exe to PATH»** на первом
экране. Без этого ничего не заработает.

### 2. Распакуй архив

Распакуй `FaceSwapApp.zip` куда угодно — например, на рабочий стол.

### 3. Установи зависимости

В папке `FaceSwapApp` найди файл **`setup.bat`** → двойной клик.

Откроется чёрное окно командной строки. Жди 5–10 минут, пока скачаются и
установятся все библиотеки (~3 ГБ).

Когда увидишь «Готово!» — нажми любую клавишу, окно закроется.

---

## Запуск приложения

Двойной клик на **`run.bat`**.

Откроется чёрное окно (не закрывай его — оно нужно для работы), а через
несколько секунд появится главное окно приложения.

При первом запуске приложение скачает ML-модели (~600 МБ) — это нормально,
происходит один раз. В правом верхнем углу будет статус «Скачивание модели…».

---

## Дальше как пользоваться

1. **Запустить камеру** — выбери в выпадайке свою веб-камеру → «Запустить камеру»
2. **Запись** — когда увидишь себя со скелетом, нажми «● Начать запись»
3. **Лицо для замены** — перетащи фото или видео в нижнюю область («Лицо для замены»)
4. **Заменить лицо** — после остановки записи нажми «Заменить лицо в записи»
5. **Готово** — нажми «Открыть папку с результатами»

Готовое видео будет в папке `output/` с названием `swapped_<дата>.mp4`.

## Если что-то пошло не так

### При запуске setup.bat: «Python не найден»
Не поставил галочку «Add to PATH» при установке Python. Переустанови с галочкой
или добавь Python в PATH вручную.

### При запуске setup.bat: ошибка установки зависимостей
Скорее всего, у тебя Python 3.12 или новее. Поставь именно **3.11**.

### При запуске run.bat: окно открывается и сразу закрывается
В скрипте есть пауза при ошибке, поэтому окно должно остаться. Если оно всё
равно закрывается — открой `cmd.exe` вручную, перейди в папку проекта
командой `cd путь\к\FaceSwapApp` и запусти `run.bat` оттуда. Тогда увидишь
текст ошибки.

### Камера не находится
Проверь, что:
- Камера не используется другим приложением (Zoom, Skype, OBS)
- В настройках Windows: «Конфиденциальность» → «Камера» → разрешить доступ
  настольным приложениям

### Face swap делает «не то лицо» / лицо плохо подменяется
Используй фото-источник, где:
- Лицо большое и в фокусе (не меньше 200x200 пикселей)
- Фронтальный ракурс, без сильного поворота
- Хорошее освещение, без сильных теней
- Только одно лицо на фото (если несколько — берётся самое крупное)

### Обработка очень долгая
На GTX без CUDA-сборки `onnxruntime` всё работает на CPU. Минута видео
обрабатывается 5–15 минут — это нормально для CPU. Чтобы ускорить, нужно
устанавливать CUDA-версию `onnxruntime-gpu`, но это отдельная история.

## Важно про папки

- **Не удаляй папку `venv`** после установки — там все зависимости (около 3 ГБ)
- **Не перемещай папку `FaceSwapApp` в другое место после `setup.bat`** —
  пути в `venv` привязаны к месту установки. Если переместил — удали `venv`
  и запусти `setup.bat` заново
- Записанные видео и результаты — в папке `output/`
- ML-модели — в папке `models/`, скачиваются один раз
