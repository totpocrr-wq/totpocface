# Сборка установщика через GitHub Actions

Этот гайд — для тебя. Здесь пошагово, как получить готовый
`FaceSwapStudio_Setup.exe`, не устанавливая Python и ничего другого.

---

## Что тебе понадобится

- Аккаунт на **GitHub** (бесплатный) — [github.com/signup](https://github.com/signup)
- Браузер
- 15 минут времени

**Всё.** Никакого Python, никакого Inno Setup на твоём компьютере.

---

## Шаг 1. Создай репозиторий

1. Зайди на [github.com](https://github.com), залогинься
2. Справа сверху нажми **«+»** → **«New repository»**
3. Заполни:
   - **Repository name**: `faceswap-studio` (или любое другое)
   - **Public** или **Private** — на твоё усмотрение (Actions работают и там, и там)
   - Галочки `Add a README` / `.gitignore` / `license` — **НЕ ставь**, у нас уже всё есть
4. Нажми **«Create repository»**

---

## Шаг 2. Загрузи код

### Вариант А — через сайт GitHub (проще, без Git)

1. На странице нового репозитория нажми **«uploading an existing file»**
   (ссылка в центре страницы)
2. Распакуй мой архив `FaceSwapApp.zip` у себя на компьютере
3. **Выдели всё содержимое** папки `FaceSwapApp/` (не саму папку, а файлы внутри!)
4. Перетащи их в окно загрузки на GitHub
5. **Важно:** убедись, что папка `.github/workflows/` тоже загрузилась —
   она скрытая, проверь, что в ней есть файл `build.yml`
6. Внизу нажми **«Commit changes»**

### Вариант Б — через Git (если умеешь)

```bash
cd FaceSwapApp
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/ТВОЙ_ЛОГИН/faceswap-studio.git
git push -u origin main
```

---

## Шаг 3. Запусти сборку

1. На странице репозитория нажми вкладку **«Actions»** (вверху)
2. Если GitHub спросит «I understand my workflows, go ahead and enable them» —
   подтверди
3. Слева увидишь workflow **«Build Windows Installer»** — кликни по нему
4. Справа появится кнопка **«Run workflow»** — нажми
5. В выпадайке оставь `Branch: main` → **«Run workflow»** (зелёная кнопка)

Сборка запустится. **Жди примерно 15 минут** — установка зависимостей и
PyInstaller небыстрые. Можешь закрыть вкладку и вернуться позже.

Прогресс видно в реальном времени, если кликнуть на запущенный workflow.

---

## Шаг 4. Скачай готовый `.exe`

Когда сборка завершится (зелёная галочка ✓):

1. Кликни на завершённый workflow run
2. Прокрути вниз до раздела **«Artifacts»**
3. Увидишь два архива:
   - **`FaceSwapStudio-Installer`** ← это тот самый установщик, ~2 ГБ
   - **`FaceSwapStudio-Portable`** ← портативная версия (без установщика)
4. Кликни на **`FaceSwapStudio-Installer`** — скачается `.zip`
5. Распакуй — внутри **`FaceSwapStudio_Setup.exe`**

**Это и есть твой инсталлятор.** Двойной клик → как любая программа.

---

## Шаг 5. Раздавай пользователям

`FaceSwapStudio_Setup.exe` — это **самодостаточный файл**. Внутри уже всё:
Python, библиотеки, Qt, OpenCV. Пользователю ничего ставить не нужно.

Где разместить:
- **GitHub Releases** — самый чистый способ (см. ниже)
- **Google Drive / Яндекс.Диск** — простой вариант
- **Свой сайт / Telegram-канал** — как угодно

## Бонус: автоматический Release при тегах

Хочешь, чтобы при выпуске новой версии **автоматически** появлялась страница
скачивания на GitHub? Это уже настроено в workflow.

После того, как ты сделал коммит:

1. На странице репозитория справа — раздел **«Releases»** → **«Create a new release»**
2. **Choose a tag** → введи `v0.1.0` → **«Create new tag»**
3. **Release title**: например, `FaceSwap Studio v0.1.0`
4. **Description**: что нового
5. Нажми **«Publish release»**

Workflow запустится автоматически, соберёт `.exe` и **прикрепит его к релизу**.
Через 15 минут на странице релиза появится готовый `FaceSwapStudio_Setup.exe`,
который можно скачать одной ссылкой. Удобно для раздачи.

## Если что-то пошло не так

### Сборка падает на «Install dependencies»
Скорее всего — конфликт версий пакетов. Зайди в `Actions` → кликни на упавший
run → раскрой раздел с ошибкой → пришли мне текст последних строк, починю.

### Сборка падает на «Build with PyInstaller»
Чаще всего — нехватка хидден-импортов. То же самое: пришли лог, добавлю.

### Артефактов нет, но workflow «зелёный»
Значит сборка прошла, но что-то с upload — проверь раздел Summary вверху run.

### `.exe` не запускается на твоём компьютере
- Проверь, что у тебя Windows 10/11 64-bit
- Windows SmartScreen может ругаться: **«More info»** → **«Run anyway»**
- Антивирус: добавь в исключения. PyInstaller-сборки иногда триггерят false positive

### Я хочу пересобрать после изменений
Просто закоммить новые файлы → Actions запустится автоматически (если настроил
триггер `push`) или нажми **«Run workflow»** вручную.

## Сколько это стоит

GitHub Actions для **публичных** репозиториев — **бесплатно неограниченно**.

Для **приватных** репозиториев — 2000 минут в месяц бесплатно. Одна сборка
~15 минут, то есть около **130 сборок в месяц бесплатно**. Тебе хватит с запасом.

## Краткая шпаргалка

| Действие | Как |
|----------|-----|
| Собрать `.exe` сейчас | Actions → Build Windows Installer → Run workflow |
| Создать релиз с `.exe` | Releases → Create release → тег `v0.1.0` → Publish |
| Найти готовый `.exe` | Actions → последний run → Artifacts |
| Пересобрать | Закоммитить изменения или повторить «Run workflow» |
